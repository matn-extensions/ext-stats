# Document Statistics

Live document word count, character count, and estimated reading time

## Details
- **Identifier**: `matn.ext.stats`
- **Version**: `1.0.0`
- **Category**: `tools`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Document Statistics**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-stats
```
